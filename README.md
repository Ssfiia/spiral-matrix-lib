# spiral-matrix-lib
Асинхронная библиотека: загружает квадратную матрицу по URL и возвращает
её обход по спирали против часовой стрелки от левого верхнего угла.

Ссылка на исходное задание:
https://github.com/avito-tech/python-trainee-assignment

## Что сделано
- 'async def get_matrix(url: str) -> list[int]' — загрузка через aiohttp
- Разбор ASCII-таблицы в матрицу
- Обход по спирали против часовой стрелки
- Работает на квадратных матрицах любой размерности
- Тест на test case из ТЗ

## Что не сделано и почему
- ошибки сервера и сетевые ошибки (5xx, Connection Timeout, Connection Refused) — не хватит времени, основной сценарий от них не зависит

## Как запустить
- pip install -r requirements.txt 
- pip install pytest
- python -m pytest -v
- python run.py

## Как проверитть
- python -m pytest -v  →  test_get_matrix PASSED, означает верно выполненную работу
- python run.py → [10, 50, 90, 130, 140, 150, 160, 120, 80, 40, 30, 20, 60, 100, 110, 70],  результат обхода матрицы по спирали: против часовой стрелки, начиная с левого верхнего угла.
